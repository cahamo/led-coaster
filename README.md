# led-coaster

A 3D printable panel in the shape of a drinks coaster that is backlit by a matrix of individually addressable RGB LEDs.

This repository contains CAD (.stl) files for the project's 3D printed components. These files can be found in the `cad` directory.

There is no programming source code associated with the project.

A description of the project build can be found on the [LED Coaster](https://cahamo.delphidabbler.com/projects/led-coaster/) page of the Cahamo website.
